## 📋 Обзор

**InDevice ADB** управляет полным потоком беспроводного сопряжения и
подключения ADB из Termux: обнаруживает устройства в сети через NsdManager,
запрашивает 6-значный код сопряжения через уведомление Android, подключается,
переподключается и обрабатывает повторные попытки при устаревании кэша
NsdManager.

Сопутствующее Android-приложение (`com.indevice.adb`) определяет языковые
настройки устройства и предлагает интерфейс на **5 языках** (pt, en, es, zh,
ru). Shell-скрипты следуют тем же настройкам локали через `--lang`.

## ⚡ Быстрый старт

1. **Установите APK** — скопируйте `indevice-adb_debug.apk` на `/sdcard/` и
   откройте на устройстве для установки. Откройте приложение один раз, чтобы
   предоставить разрешения на уведомления.
2. **Установите скрипты** — `bash install.sh`
3. **Включите беспроводную отладку** на целевом устройстве (Параметры
   разработчика)
4. **Запустите:** `adb-pair`

## 🔧 Команды

| Команда | Описание |
|---------|----------|
| `adb-pair` | Полный поток: ping → обнаружение → подключение (или сопряжение → подключение) |
| `adb-connect` | Быстрое подключение с автоматическим обнаружением |
| `adb-reconnect` | Переподключение к последнему сохранённому устройству |
| `adb-discover` | Обнаружение устройств (mDNS → NsdManager → локальное сканирование) |
| `adb-parity-setup` | Управление установкой: install \| uninstall \| status \| apk |

**Общие флаги:** `--help`, `--verbose`, `--json`, `--lang pt|en|es|zh|ru`,
`--no-notify`, `--timeout N`, `--connect-only`
